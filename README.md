# Power BI Project Management Dashboard

This repository contains a **Power BI dashboard** built to analyze and monitor project performance for a fictional organization. It provides executives, project managers, and analysts with actionable insights on project KPIs, budgets, workload distribution, status, priority, and geographic performance.

---

## 📝 Overview

The dashboard includes **two main pages**:

1. **Summary Insights Page** – High-level KPIs, trends, and visual summaries.  
2. **Detailed Data Table Page** – Complete project-level breakdown with interactive filters.

Navigation is implemented using **Power BI bookmarks** and **custom sidebar icons** for an app-like user experience.

---

## 📊 Key Features

### 1️⃣ KPI Cards
- Total Projects: 83  
- Total Budget & Expense  
- Budget Utilization %  
- Embedded mini line-charts for trend visibility  

### 2️⃣ Budget & Expense Trend
- Multi-series line chart by quarter  
- Tracks seasonal patterns, cost spikes, and budget vs. actual variance  

### 3️⃣ Project Categorization
- Projects by Status, Type, and Manager  
- Highlights bottlenecks and workload distribution  

### 4️⃣ Project Priority Insights
- Donut chart showing project priorities  
- Identifies high-risk or urgent projects  

### 5️⃣ Geographic Distribution
- Filled U.S. map showing project counts per state  
- Supports regional comparison and resource allocation  

### 6️⃣ Detailed Table View
- Columns: Manager, Type, Status, Priority, Dates, Budget, Expense, Utilization  
- Filters for Type, Location, Status, Priority, and Date Range  

---

## 🧩 Technical Components 
- **DAX:** Measures and calculated columns for KPIs and metrics  
- **Bookmarks & Custom Icons:** For seamless navigation  
- **Conditional Formatting:** Highlights key insights
